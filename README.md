# Getallenbos

Spel voor groep 1–2 op een staande iPad. Gebruikt de aangeleverde illustraties. Eén speler tegen de computer of twee spelers tegenover elkaar. De bovenste kaarten zijn 180 graden gedraaid.

Gooi en tik de kaart met hetzelfde aantal aan. Een herhaalde worp draait die kaart terug. Een verkeerde keuze verbruikt geen beurt. Kies als eerste alle zes om, of ieder tien beurten en daarna de meeste kaarten om. In de tweede spelvorm tonen eikels én een cijfer hoeveel beurten over zijn. Gelijkspel is mogelijk.

Een felle rand wijst de actieve kaartenrij aan. De luidspreker met herhaalpijl herhaalt de laatste Nederlandse aanwijzing. De bovenkant van de houten 3D-dobbelsteen toont de worp met rode stippen. Karakters gebruiken de drie aangeleverde emoties.

## Spelen

Publiceer de hoofdmap met GitHub Pages (Settings → Pages → Deploy from a branch → main, / root). Open de gepubliceerde link in Safari. Kies Deel → Zet op beginscherm voor beeldvullend spelen. De indeling is gemaakt voor de iPad 9e generatie (810×1080 CSS-pixels). Nederlandse spraak gebruikt de beschikbare apparaatstem.

## Lokaal

`npm run dev` opent een server op http://127.0.0.1:4174. `npm test` controleert spelregels en alle zes dobbeloriëntaties. Geen installatie of externe bibliotheken nodig voor het spel.
